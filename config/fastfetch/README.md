# Nyarch-style fastfetch

Uses the original Nyarch cat-eared Arch artwork with a custom Catppuccin Mocha
information layout. The operating system is still reported accurately as Arch.
Kitty displays the PNG directly, so ImageMagick is not required.

Artwork source:
https://github.com/NyarchLinux/NyarchLinux/blob/main/Gnome/etc/skel/.config/fastfetch/logo.png
Original layout inspiration (by Bina):
https://github.com/NyarchLinux/NyarchLinux/blob/main/Gnome/etc/skel/.config/fastfetch/config.jsonc

`NYARCH-LICENSE` contains the upstream GPL-3.0 license. The image is unmodified.
